# Данные

| Папка | Что это | Статус |
|---|---|---|
| `golden/` | Учебный пример из паспорта: 4 города, 6 пар. **Тестовая фикстура** — числа придуманы для проверки формул. | синтетика |
| `demo/` | 12 крупных городов; время поездки **оценено по расстоянию** скриптом `scripts/make_demo_data.py` при допущениях о скоростях и наличии авиации. | синтетика |
| `real/` | Сюда класть таблицы организаторов («Точно: связность городов», «Точно: населённые пункты»). | **пусто — файлов в переданных материалах нет** |

Реальные и синтетические данные не смешивать: в отчётах метка источника попадает в лист «Параметры».

## Формат таблицы пар (`*_pairs.csv`)

```
city_a,city_b,time_auto,time_rail,time_air
Казань,Екатеринбург,,10,
```
Время — в часах. Пустая ячейка — вида транспорта между городами нет. Порядок городов в паре не важен.

## Формат таблицы населения (`*_population.csv`)

```
city,population
Казань,1.3
```
Единицы задаются ключом `--pop-unit` (`mln` по умолчанию, `thousand`, `people`).
